# Chrome 网上应用店上架文案（中文）

## 名称
芒果句库 MangoSentences

## 简短说明（建议）
划词翻译，一键存句，看中文默写英文。

## 详细描述（可直接粘贴）

芒果句库帮你在浏览英文网页时，把好句子留下来，并用「看中文、写英文」的方式复习。

主要功能：
- 划词即可本地翻译（基于 Chrome 内置翻译能力，无需第三方 API Key）
- 一键保存句子、中文翻译与来源页面
- 填空式复习：按单词默写，实时对错反馈
- 句子仓库：查看全部收藏与复习状态
- 数据仅存本机，支持导出 / 导入 JSON

适合想在真实阅读中积累句子、巩固语感的英语学习者。

## 分类建议
教育（Education）或 生产力（Productivity）

## 单一用途声明（Privacy 页）
帮助用户在网页上划词翻译并保存句子，以便本地复习英文表达。

## 权限理由（可填在 Privacy）
- storage / unlimitedStorage：本地保存句子与设置
- contextMenus：右键翻译并保存
- notifications：保存结果提示
- offscreen：运行 Chrome 本地翻译
- 读取网页内容：划词浮层与保存来源信息
