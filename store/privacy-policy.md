# 芒果句库（MangoSentences）隐私政策

最后更新：2026-10-12

## 我们收集什么数据

芒果句库是一款 Chrome 扩展。默认情况下：

- **不会**把你的浏览内容、句子或设置上传到我们的服务器。
- 你划词保存的英文句子、中文翻译、来源页面信息与复习进度，仅保存在**你本机的 Chrome 本地存储**（`chrome.storage.local`）中。
- 翻译使用 **Chrome 内置 Translator API** 在本地完成，不经过本扩展开发者的服务器。

## 权限说明

扩展可能申请以下权限，用途如下：

| 权限 | 用途 |
|---|---|
| `storage` | 在本地保存句子与设置 |
| `unlimitedStorage` | 避免收藏较多句子时本地存储受限 |
| `contextMenus` | 提供「翻译并保存」右键菜单 |
| `notifications` | 保存结果等本地通知 |
| `offscreen` | 在扩展页面中运行本地翻译能力 |
| 访问网页内容（content script / host） | 在你浏览的页面上划词翻译与展示浮层 |

我们不会利用这些权限投放广告，也不会出售用户数据。

## 数据导出与删除

- 可在扩展「设置」中导出 JSON 备份。
- 可在「设置」中清空本地数据；清空后无法自动恢复。
- 卸载扩展后，Chrome 通常会删除该扩展的本地存储（以 Chrome 实际行为为准）。

## 第三方服务

本扩展不依赖开发者自建后端。翻译能力依赖你所使用的 Chrome 浏览器提供的本地翻译功能；Chrome / Google 自身的数据处理适用其隐私政策。
